# Simple Blog App

A colorful Java Swing desktop application that allows users to create, read, and delete blog posts.

## Features
- Create blog posts with a title and content
- View and read saved posts
- Delete selected posts
- Colorful and user-friendly GUI
- Local file storage for persistent data

## Technologies
- Java
- Java Swing
- File Handling
- Object Serialization

## How to Run
1. Open the project in NetBeans.
2. Run `SimpleBlogApp.java`.
3. Enter a post title and content.
4. Click Add Post to save your post.
5. Select a post to read or delete it.
